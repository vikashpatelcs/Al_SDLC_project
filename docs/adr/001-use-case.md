# ADR 001: Representative Financial Use Case Selection

- **Status**: Accepted
- **Date**: 2026-10-06

## Context
Problem Statement requires starting with a representative financial domain (Customer Onboarding & KYC or Loan Processing).

## Decision
Select Digital Customer Onboarding + KYC as the primary development use case, and Loan Processing as the secondary benchmark case.

## Consequences
Allows grounded verification against a compact, well-defined corpus of RBI Master Directions, PMLA 2002, and DPDP Act 2023, while naturally extending to account opening, fund transfers, and fraud alerts.
